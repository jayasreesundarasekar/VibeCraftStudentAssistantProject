# AttendGuard + Free Class Locator
Open `index.html` in Chrome/Edge (internet needed for fonts and PDF reader).

- data.js, app.js, extras.js, letters.js, assistant.js, boot.js: AttendGuard
- rooms.js: Free Class Locator (3D map, countdown, WhatsApp squad, AI search)
- style.css: all styles (room finder scoped under #rooms)

Outside claude.ai the AI features fall back to built-in answers.
